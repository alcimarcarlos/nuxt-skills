# Nuxt 4 Testing & Quality

## Workflow

1. Escolha o tipo de teste mínimo por risco (unit -> contract -> e2e).
2. Para `server/api`: teste contrato (status, shape, validação, auth).
3. Gates: lint + typecheck + build + tests.
